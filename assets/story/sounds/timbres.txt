# Тембри людей: яким голосом людина хмикає, зітхає, сміється (а згодом і говорить: голосовий пакет бере той самий тембр).
# Рядок «@timbre <назва> …» — не звук, а голос. Вигуки записано одним голосом (speech.txt); інструмент робить із них кожен тембр:
# node tools/sound.js timbres (його шапка каже слова like, tone, throat, air, tilt, tremor), послухати: node tools/sound.js page.
# Кому який дістається, вирішує гра (NpcTimbre) за словами:
#   for=man|woman      чий це голос          age=young,grown,old   якому вікові пасує (поселенець має вік; людина сюжету — «grown»)
#   pitch=0.95..1.05   у цих межах кожна людина має ще свій тон (швидше й вище чи повільніше й нижче)
#   only               лише тому, кому написано в його файлі: «timbre: <назва>»
#   hero               голос головного героя (гравця): ним герой бурмоче свої відповіді в розмові; людям не роздається. Героєві
#                      дістається один із «hero» своєї статі навмання, раз, і тримається в персонажі (NpcTimbre.OfHero)
#   of=rec1            тембр зроблено не з першого запису, а з дублів записаного голосу rec1 (рядок із «rec»): той самий інструмент, ті самі слова
# Людина тримає обраний тембр назавжди: новий рядок тут дістається лише новим людям, голоси наявних не міняються.
# «@pool <число>» — покоління пулу. Число більше, ніж було: КОЖЕН поселенець обирає голос наново з теперішнього пулу (один раз) і
# далі тримає вже його. Піднімати лише коли автор каже перероздати голоси всім; людей із «timbre:» у файлі це не чіпає.
# Новий тембр — новий рядок і знову «timbres». Тембр без like/tone/throat/air/tilt/tremor — сам запис, як він є.
#   like=Speaker_53    ІНШИЙ голос: гра запису (мелодія, гучність, ритм) тембром одного з безіменних голосів моделі озвучки
#                      (tools/sound_voice.py). Зсув записаного голосу (tone, throat) лишається для вуха тим самим голосом.
# У тембр переробляються лише дублі, де майже все — голос (або майже все — повітря); дубль, де голос і видих разом, лишається тільки
# в записі як є. Вигук, якого не можна переробити зовсім («кхм»: голос і шум одразу), чоловічі тембри кажуть самим записом, жіночі — мовчать
# (рядок «@none» у файлі тембру), доки не буде запису жіночим голосом.
#
# ---- Запис як є: голос автора. Поселенцям не роздається (only): автор чув себе в кожному чоловікові (2026-11-13)
# У моді з нього лише те, що грає як є: по одному дублю на вигук (назва вигуку, її гучність і розкид — у speech.txt) і всі «кхм» (їх кажуть
# записом чоловічі тембри з нього). Усі дублі живуть нестисненими в sound_masters (лише на машині автора): із них робляться тембри.
@timbre own  only for=man pitch=0.95..1.05                                   # запис як є (голос автора)
#
# ---- Пул поселенців (роздає гра): початковий, із двох записів — автора і другої людини (автор, 2026-11-13: «змішай з нашими, щоб вже був
# пул початковий цікавих нових голосів, і старим нпс теж тоді заміни при збірці новій» → @pool 2); потім — записи інших людей.
@pool 2
# Із запису автора: три чоловічі й три жіночі («залиш по 3 варіації мого, інші дам потім і розбавимо»). Це гра запису з висотою й сталим
# забарвленням голосів моделі озвучки (like=), найдальші один від одного за висотою з чотирнадцяти пробуваних; для вуха — той самий голос
# на різній висоті (заміряно: схожі один на одного на 0,85–0,92).
# Справжні голоси — записи інших людей: node tools/sound.js voice <назва> <тека> --for man|woman. Вік усюди — здогад за висотою, не на слух.
@timbre m1   for=man   age=grown,old        pitch=0.96..1.04  like=Speaker_24    # низький: 99 Гц
@timbre m2   for=man   age=young,grown,old  pitch=0.96..1.04  like=Speaker_0     # середній: 109 Гц
@timbre m3   for=man   age=young,grown      pitch=0.96..1.04  like=Speaker_29    # вищий: 130 Гц
@timbre f1   for=woman age=grown,old        pitch=0.96..1.04  like=Speaker_43    # низький жіночий: 181 Гц
@timbre f2   for=woman age=young,grown,old  pitch=0.96..1.04  like=Speaker_17    # середній жіночий: 194 Гц
@timbre f3   for=woman age=young,grown      pitch=0.96..1.04  like=Speaker_59    # вищий жіночий: 218 Гц
# Записані голоси інших людей (rec: власні дублі людини, нічого не перероблено). for= і age= каже автор на слух, інструмент їх не чує.
# rec1: запис 2026-11-13 (voice-proto/rec/voices/new1), 56 дублів, без «вдиху»; у читанні 153 Гц, у вигуках 123–354 Гц. Висота й розмір
# горла — між чоловічими та жіночими зразками; for=man — зі слів автора (2026-11-13: «у друга чоловічий»); на сторінці він голос послухав: «Супер».
@timbre rec1     for=man   age=young,grown      pitch=0.96..1.04  rec
# Варіації rec1 (of=rec1: зсув висоти й горла вокодером; кожна тримає по 4 дублі вигуку). Висоти — рахунок від 153 Гц читання, не замір.
@timbre r1_low   for=man   age=grown,old        pitch=0.96..1.04  of=rec1 tone=0.82 throat=0.95                          # нижчий, більше тіло: ~125 Гц
@timbre r1_old   for=man   age=old              pitch=0.97..1.03  of=rec1 tone=0.88 throat=0.97 air=0.3 tilt=-1 tremor=0.03   # старий: ~135 Гц, з повітрям, тремтить
@timbre r1_w1    for=woman age=grown,old        pitch=0.96..1.04  of=rec1 tone=1.22 throat=1.09                          # жіночий нижчий: ~187 Гц
@timbre r1_w2    for=woman age=young,grown      pitch=0.96..1.04  of=rec1 tone=1.36 throat=1.13                          # жіночий вищий: ~208 Гц
@timbre r1_wold  for=woman age=old              pitch=0.97..1.03  of=rec1 tone=1.18 throat=1.08 air=0.3 tremor=0.03      # стара: ~180 Гц, з повітрям, тремтить
@timbre rec2  for=man  age=young,grown,old  pitch=0.96..1.04  rec    # власний запис людини: rec2
@timbre r2_w1    for=woman age=grown            pitch=0.96..1.04  of=rec2 tone=1.62 throat=1.15                          # жіночий середнього віку (користувач 2026-11-15: із другого запису — жіночий молодий і середнього віку)
@timbre r2_w2    for=woman age=young            pitch=0.96..1.04  of=rec2 tone=1.8 throat=1.18                           # жіночий молодий
@timbre rec3  for=man  age=young,grown,old  pitch=0.96..1.04  rec    # власний запис людини: rec3
#
# ---- Голоси головного героя (hero): ними гравець бурмоче свої відповіді в розмові; людям не роздаються. Гра дає героєві один із них
# його статі навмання, раз (NpcTimbre.OfHero). Автор, 2026-11-16: «зроби нову сущность для головного героя … рандомно присвоєний з цього пулу поки що».
# rec4: запис 2026-11-16 (voice-proto/rec/voices/new4: вісім «Neue Aufnahme» без назв; який де звук — за розпізнаванням мови й заміром, не на
# слух; «Вдих» — п'ять подихів перед вигуками, вирізані з них). По дублю на вигук, без «о» і «кхм». «зроби 3 варіанти для жінки та чоловіка»:
# сам запис і два чоловічі зсуви, три жіночі. Висота — заміряна (pyworld, медіана вигуків без вдиху й смішку).
# creak=60: цей голос гуде чисто нижче за 78 Гц («хм», «емм» — 70–75 Гц без шуму); із 78 три вигуки з шести вважалися скрипом і не робились.
@timbre rec4     for=man   hero  age=grown,old        pitch=0.96..1.04  rec creak=60                                       # сам запис: 81 Гц
@timbre r4_m     for=man   hero  age=young,grown      pitch=0.96..1.04  of=rec4 tone=1.28 throat=1.04                          # вищий, молодший: 100 Гц
@timbre r4_old   for=man   hero  age=old              pitch=0.97..1.03  of=rec4 tone=1.1 throat=0.98 air=0.3 tilt=-1 tremor=0.03    # старий: 88 Гц, з повітрям, тремтить
@timbre r4_w1    for=woman hero  age=grown,old        pitch=0.96..1.04  of=rec4 tone=2.05 throat=1.15                          # жіночий нижчий: 162 Гц
@timbre r4_w2    for=woman hero  age=young,grown      pitch=0.96..1.04  of=rec4 tone=2.3 throat=1.2                            # жіночий вищий: 182 Гц
@timbre r4_wold  for=woman hero  age=old              pitch=0.97..1.03  of=rec4 tone=2.0 throat=1.14 air=0.3 tremor=0.03       # стара: 158 Гц, з повітрям, тремтить
