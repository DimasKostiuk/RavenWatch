# Люди саги (StorySaga): стрічка «Люди» на вкладці «Сага». Місця — places.txt, знання — lore.txt, загадки — riddles.txt: формат той самий,
# блок каже свій розділ книги: [person …], [place …], [lore …], [riddle …]. Назва запису — літери, цифри, «_»; одна на всі файли саги.
# Запис людини зветься так само, як її розмова ([person heid] ↔ [talk heid]): під відкритим записом книга каже, хто може розповісти більше
# (рядок, що чекає на «asked» і ще може бути почутий), і бере ім'я звідси — таким, яким гравець його зараз знає.
#
#   [person echo]
#   chapter: prologue                  глава, з якою запис з'являється (книга групує за нею)
#   shown: lived prologue.echo         умови: запис є в книзі. Кілька рядків — досить будь-якого. Без рядка — щойно відкрився
#                                      хоч один його line: чи quote:
#   name: flag know_eirik :: Ейрік     ім'я, як воно відоме зараз: перший рядок, чиї умови справджуються («<умови> :: <слова>»);
#   name: Відлуння                     останній — без умов: як його звати, поки більше не відомо. Так запис дописується з часом:
#                                      новий рядок із умовою над старим, і книга покаже його, щойно умова справдиться
#   about: постать у покинутій хаті    слово-два під іменем: перший рядок, чиї умови справджуються (можна без нього)
#   line: <умови> :: <слова>           що про нього відомо: рядок з'являється, щойно умови справджуються; без умов — разом із записом.
#                                      Рядок, який пізніші слова замінюють, каже це сам («!flag …»)
#   quote: zala.rizba Різьба           що гравець прочитав на цій деталі місця (її read: у locations.list), слово в слово, під цим підписом
#   map: been zala :: hall             «Показати на мапі»: перший рядок, чиї умови справджуються, називає місце
#
# Умови — звичайні умови сюжету (StoryCond), і тут можна «або»: «a, b | c» — a і b, або c. Найчастіші:
#   lived <квест>.<етап>[.<шлях>]      запис власного літопису вже є (етап чи шлях із saga: пройдено)
#   knows <подія>                      подію світу (assets/story/tales) гравець бачив, чув від людини чи знає й так
#   asked <розмова> [місце розмови]    гравець чув це місце розмови (до нього привела відповідь): так у Сагу лягає те, що розпитано;
#                                      без місця — говорив із цією людиною взагалі
#   read <місце>.<деталь> [full]       гравець прочитав слова деталі (E на ній); «full» — саме її перший рядок read: (повний текст,
#                                      а не «текст пливе перед очима»)
#   been <місце>                       гравець стояв на землі цього місця
#   flag <назва>                       прапорець, який поставила розмова («!flag x»), сцена («do flag x») чи етап («done: flag x»)
# Книга нічого свого не зберігає, крім «прочитано»: що відомо, питається щоразу з того, що сюжет і так пам'ятає.
# Пиши лише те, що гравець справді бачив, чув чи прочитав: слова людей — як їхні слова, без висновків за нього.
# Подія сервера: рядок відкриває «knows <подія>» (бачив або переказали), а не стан світу, і каже лише те, що каже запис самої події
# (її saga: у tales) — переказ може не знати, хто це зробив. Сцена сервера в персонажі нічого не лишає: на неї умови нема.

# Ім'я відкриває різьба Зали, прочитана при вогні Варти (користувач 2026-11-16): «Я Ейрік. Я лишився сам» — «read zala.rizba full».
[person eirik_raven]

line: lived prologue.circle :: Кружляв над тобою й показав два сліди: один іржавіє в траві, другий стоїть на роздоріжжі й досі показує не туди.

# Гейд: у книзі з першої розмови з нею («asked heid» без місця — будь-яке місце її розмови) і лише у світі, де вона вже є.
