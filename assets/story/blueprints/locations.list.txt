# RavenWatch: місця сюжету (по одному в кожному світі). Див. src/Loc.cs — Locs.
# loc <креслення>  name: назва  biome: біом гри  from: start мін макс далеко | <інше місце> мін макс [edge — між стінами]
# clear: м без будівель гравців  nobuild: м без будування  states: стани через кому, субстани стану в дужках через / (закинута (розпалена / ...))  ruin: стани-руїни 1..N
# grass: yes — уся трава лишається; N — голий ґрунт лише N м від середини, далі трава; без рядка — ґрунт під підлогою
# touch: <назва деталі> <умови> — деталь світиться, поки умови (StoryCond) справджуються, E на ній — подія «use <місце>.<назва>»
# follows: hall — стан іде за Залою (1 до розпаленої, 2 з неї: табір Гейд)
# sink: на скільки м нижче в землі, ніж збережено  fog: yes|no (туман Хели в руїні)  ruinlit: що горить і в руїні (префаби через пробіл)  litfrom: крок префаби — горять у руїні з цього кроку (1.2 hearth)  keys: основа ключів світу (лише Зала: старі)
