# loc <креслення>  name: назва  biome: біом гри  from: start мін макс далеко | <інше місце> мін макс [edge — між стінами] [nearest — найближча така земля: кільце від середини назовні]
# room: перед/зад боки — м своєї землі за стінами креслення (шукається, рівняється й чиститься разом із місцем)
# clear: м без будівель гравців  nobuild: м без будування  states: стани через кому, субстани стану в дужках через / (закинута (розпалена / ...))  ruin: стани-руїни 1..N
# grass: yes — уся трава лишається; N — голий ґрунт лише N м від середини, далі трава; без рядка — ґрунт під підлогою
# alias: hall — інші слова, якими дані сюжету кличуть це місце · refuge: yes — дім воронів: туди йдуть ненайняті люди
# gate: <назва деталі> — головна брама: зачинена й замкнена, поки сюжет не відчинить (gate <місце> open) · hearthshut: <слова> — що каже вогнище, поки брама замкнена · hearthgives: <предмет> — вогонь Варти дає на E один такий, одну за раз (Зала: Жарина, що розпалює серце оселі) · hearthgivewait: <умови> :: <слова> — того, що дає (hearthgives), не дає, поки умови справджуються, і каже ці слова · hearthwait: <умови> :: <слова> — вогнище не розпалюється, поки умови справджуються для гравця (сюжет ще не дійшов), і каже ці слова
# touch: <назва деталі> [anim] [quiet] <умови>|- — деталь світиться (quiet — ні), поки умови (StoryCond) справджуються, E на ній — подія «use <місце>.<назва>»
# read: <назва деталі> [<умови> ::] <слова> — що показує E (перший рядок, чиї умови справджуються; \n — новий рядок)
# pool: <назва> <імена через кому> — список, з якого слова read: беруть імена: «{pool <місце>.<назва> <скільки> [<у рядку>]}» (у рядку — 3). Котрі саме, вирішує зерно світу: в одному світі всі читають ті самі, в іншому інші (LocTouch.Shown)
#   нічого не зберігається: ім'я, дописане в кінець списку, інших не зсуває, але може стати замість котрогось у вже початих світах; переклад списку має стільки ж імен у тому ж порядку (storycheck)
# elsedo: <назва деталі> <дії> —дії сюжету на дотик, якого не чекає жоден твій етап (лист, прочитаний поза прологом: серце відкривається одразу)
# mapmark: <умови> — золотий знак місця на мапі для того, для кого умови справджуються
# mappin: <умови> — щойно умови справдились, постійна мітка гри (вогонь) з назвою місця на мапі гравця: ставиться раз на світ, стерта правим кліком не вертається (MapKeep)
# becomes: <стан.субстан> <умови світу> — сервер переводить місце на цей крок, щойно умови справджуються (по порядку, лише вперед, за кадром:
#   одразу до найдальшого кроку, що справджується; чекає, доки нікого поруч, а після завантаження світу — одразу, LocState)
# follows: <стан> <умови світу> — цей стан, поки умови справджуються, інакше перший (табір Гейд)
# cold: <умови світу> — у будівлі холодно, поки умови справджуються · fog: yes|no|<умови світу> — туман Хели в руїні (поки умови)
# умови світу: world, wvar, placed, gate, hearth, state (state zala >= 1.2) — сервер питає їх без гравця
# hidewhile: <назва деталі> <умови> — деталі для гравця нема, поки умови для нього справджуються (кілька рядків: досить будь-якого); умови світу — її нема для всіх (старий лист у Залі, прочитаний)
# statewhile: <стан> <умови> — кожен гравець бачить місце у своєму стані: цей, поки умови справджуються, інакше перший (хата Ейріка: обжита до книги)
# apart: <місце> <м> — середина щонайменше за стільки від середини іншого місця (Хугін і Мунін)
# inside: <розклад> [door <назва деталі>] — над місцем висить нутро з кімнат гри (assets/story/rooms/<розклад>.txt: tools/rooms.js, LocInside); E на цій деталі — вхід
#   («Увійти»), вихід усередині веде назад перед неї. Точки нутра в даних сюжету: in.<розклад> (де входять), in.<розклад>.<точка>
# shell: <місце гри> [x y z поворот] — над місцем стоїть вигляд місця гри (курган склепу: Crypt2, Crypt3, Crypt4) без його власного підземелля;
#   стає так, що вхід кургану гри збігається з деталлю door рядка inside:; числа — зсув (вправо, вгору, вперед від дверей) і доворот на око автора
# insideshut: <умови> :: <слова> — вхід запечатаний для гравця, поки умови справджуються; при наведенні каже ці слова
# insidemusic: <звук> [vol V] — своя музика по колу, поки гравець у нутрі цього місця (звук — трек каталогу assets/story/sounds); вийшов — музика гри; бій і сцени — над нею
# sitsay: <місце> <тег ворона> [<умови>] — гравець сів на сидіння гри біля цього місця (деталь, точка нутра; 1.5 м): твій ворон на плечі каже рядок цього тегу
#   (слова — src/SeatPatterns.cs і англійські файли воронів); кілька рядків на те саме місце — береться перший, чиї умови справджуються (LocSitSay)
# lockchests: yes — скрині не відкриваються · lockstations: yes — верстаки й кузні не станки · lockdoors: <умови> — двері замкнені для гравця, поки умови справджуються (opendoors: префаби чи назви деталей, яких це не стосується)
# shutdoors: <умови> — двері не замкнені, але для гравця стоять зачинені, поки сам не відчинить (не видно, що за ними)
# raven: <вигляд> <назва деталі> <умови> — у місці живе свій ворон (Зала: листоноша; LocRaven): вигляд з assets/story/looks, його слово тримає ZDO цієї деталі, живе, поки умови справджуються; сідає на жердини й ravensits:, часом комусь на голову, каркає, не говорить
# ravenroof: x y z — точка під дахом (у мірці креслення), крізь яку ворон вилітає й залітає: звідти прямо вгору крізь дах (пару секунд без зіткнень) і в небо; висота даху міряється щоразу
# ravensits: <префаби> — на що ворон місця сідає, крім жердин (верх деталі, рівний, з місцем над ним, у стінах; деталі, якої в стані нема, — ні)
# worn: <крок> <частка> [<крок> <частка> …] on <слова префабів> — у цьому кроці поламаний вигляд гри (міцність руїни) лише в такої частки деталей, чий префаб має одне зі слів (wall roof), усе інше ціле: ремонт почато; вибирає ядро плямами по 4 м, однаково в кожному світі; крок без рядка — як каже його стан (руїна поламана, далі ціле) (LocState.Broken)
