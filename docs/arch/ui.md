# Мова й інтерфейс: хто за що відповідає

Розділ карти `docs/ARCHITECTURE.md`: правила й «Перед словом «готово»» там, збірка й робочий цикл у `docs/jobs/build.md`, тут лише таблиці цієї частини моду. Кожен рядок: що потрібно → єдине місце в ядрі → чого не робити поруч із ним. Шапка названого файлу каже, як воно працює.

## Мова й тексти

| Що потрібно | Єдине місце | Не роби |
|---|---|---|
| Будь-який текст для гравця | `Lang.T` / `F` / `K`, україномовний ключ; англійська в `assets/lang`. `tools/l10n.js` бачить текст одразу в дужках і гілки вибору в них (`Lang.T(a ? "…" : "…")`); решту — лише позначену `Lang.K` / `Lang.Keys` | голий рядок на екрані; `Lang.T(змінна)` з тексту, ніде не позначеного |
| Текст у полі чи списку (назва кнопки, професії, стан NPC) | `Lang.K("…")` там, де пишеться (інакше `l10n.js` його не бачить), `Lang.T` там, де показується; список рядків — `Lang.Keys("…", …)`. Те, що зберігається (ZDO, лог, пошук у тексті), лишається українським; стан NPC перекладає `NpcActor.StatusText` (слово справи й `Doing` теж через `Lang.K`) | писати в ZDO перекладене; `Title = "…"` без `Lang.K`; `new[] { "…" }` для слів, що підуть у `Lang.T` |
| Позначка предмета в торбі й скрині (знак у кутку клітинки, рядок підказки) і річ, що лишається з тобою | `ItemMarks` (`ItemMarks.cs`): річ, яку сюжет забирає чи гравець віддає навмисно (розмова `!take`, плата людині, бажання, Жарина в ліхтар), — лише `ItemMarks.Take`: інакше збережену річ `ItemMarks.Tick` поверне в торбу (2026-11-15: Жарина верталась після розпалення); вид позначки — рядок `ItemMarks.Kinds` зі свого модуля (`ItemMarks.Wire`: доручення — `ErrandMarkKind` (ErrandItems.cs), сюжетні речі — `WsItems.StoryMarks`); «не губиться при смерті, не викидається» — `ItemMarks.Keeps`; зникла іншим шляхом (кошик іншого мода: мод не називає жодного) — повертається (`ItemMarks.Tick`: рахує всі завантажені скрині поруч, зокрема комірки спорядження людей; сюжет віддає її через `ItemMarks.Let`); на підставку не вішається (`ItemMarksKeepOffStands` (ItemMarks.cs)). Не охоплено: сховище іншого мода, що не є скринею гри. Сюжетна річ — рядок `story: для Кетіля` (чи `yes`) у файлі предмета; `story: … until <умови світу>` — сюжетна, поки вони не справдились, далі звичайна (`WsItems.StoryOver`, раз на `WsItems.OverEvery` с; річ у торбі, що перестала бути сюжетною, не вважається зниклою: `ItemMarks.Tick`); торговці речей моду не купують (ціна 0); рядок `pickup: hand` — річ на землі береться лише на E, гра не затягує її сама (намисто на ліжку Кетіля) | свій патч на клітинку чи підказку для нового виду позначки |
| Розмова в коді (вбудована `common`, `[talk common +]` модулів, відповіді в полях `NpcTasks`) | `tools/l10n.js` читає кожен літерал файлу з «[talk » як рядки розмови тим самим розбором, що й `assets/story/talk` (слова місця до наступного `@`, кожне `a \|\| b` окремо, як `NpcTalk.OneOf`) | слова місця розмови українським літералом у коді: їх не збере (місце говорить через `{greet}`, `{concern}`, `{@тема}`) |
| Текст у колі чи диску меню | `NpcMenu.Fit`: менший шрифт, тоді «…»; ширина підпису = відстань до сусідньої кнопки; шрифт для IMGUI: `BookArt.Words` (Alegreya) | фіксований розмір, що вилазить англійською; шрифт скіна гри |
| Скільки репліка на екрані | `RavenSpeech.Seconds(текст, Pace)`: одна функція для всіх (вид рядка: картка ворона, слова дару, сцена, людина, сюжетний ворон, балачка), над усіма `ReadScale`; час у секундах (налаштування, затримка гри) — `RavenSpeech.Hold` | своя формула часу показу |
| Хто говорить зараз | `Director`: кожен, хто хоче сказати сам, питає його | говорити повз нього |
| Складені фрази | `Patterns` і файли `*Patterns.cs`, `Composer` | фрази в коді логіки |
| Форми роду | `{m\|f}` розділяє літери, що різняться: `виріши{в\|ла}`; `Grammar`. На екран — лише через `Grammar.Fix` (форми цього гравця): у книзі це роблять `RavenBook.T`, підказки, довідка «?» і живі рядки, що оновлюються щосекунди (`RavenBook.Ticking`); повідомлення — `RavenMsg.Center`; слова ворона — його мова. Новий шлях тексту на екран повз них — з `Grammar.Fix` (користувач 2026-11-17: довідка «Шлях Одіна» показала «бу{в\|ла}») | `вирішив{\|ла}`; текст із формою прямо в `.text` |
| Голоси й мова | Мунінові суржик і русизми навмисні; Хугін дотепний і різкий (`docs/jobs/words-ravens.md`). Інтерфейс, люди й сюжет — чиста українська, без русизмів і кальок | «виправляти» Муніна; русизм чи калька в тексті інтерфейсу |

## Інтерфейс і налаштування

| Що потрібно | Єдине місце | Не роби |
|---|---|---|
| Книга воронів | `RavenBook*`; текст із підказкою золотий і з великої літери, без «?» | другий вид вікна |
| Скільки коштує сторінка книги | рядок `Book of ravens drawn` у лозі при закритті книги: кожна вкладка, побудова, розкладка, наступний кадр, що створилось при кліку (`BookArt.Late`). Форма чи картинка створюється раз і лежить у `BookArt`; дорога — здешев її там | готувати заздалегідь те, що можна зробити дешевим; своє кешування поза `BookArt` |
| Чи вміє гравець говорити з вороном | `RavenBook.Given`: у сюжетній збірці книгу дає хата Ейріка (дія `book`), без неї ворон лише сидить; клавіші, коло, голод (`Satiety.Draining`), смерть, прохання питають лише її. Хто мав ворона до сюжету, отримує книгу одразу. Без книги Провідник приносить лише теми `Bookless` (люди, `NoBook`); ворон від Гальдора без книги: тема `NoBook` одразу, а пролог скорочує свої паузи (умова `book`, розвилки `ownraven any, !book`) | свій замок у підсистемі |
| Клавіші | Свої клавіші моду: `RavenKeys`. Лише слухають, у гри й інших модів нічого не забирають. Стан кнопок гри (стрибок, присід) читай напряму через `ZInput` | перехоплювати клавішу |
| Коло дарів і наказів | `RavenRadial`, `OrdersMenu`; його картинки (рамки, значки `n-…`) для IMGUI — `OrdersMenu.Pic` (нема в збірці — чорний квадрат 4×4), для спрайта чи `RawImage` — `OrdersMenu.PicOrNone` (нема — null) | своє меню; перевірка картинки за розміром |
| Налаштування | ~35 головних у меню, решта в `tuning.cfg`. Баланс сервера іде через `ServerConfig` | новий рядок у меню без потреби |
| Ключі `Config.Bind` | без `= \n \t \ " ' [ ]`: один поганий ключ вбиває весь мод | |
| Консоль | `raven` у `Commands`, англійські слова; лише адмін, крім `raven book` | |
