# Мова й інтерфейс: хто за що відповідає

Розділ карти `docs/ARCHITECTURE.md`: правила й «Перед словом «готово»» там, збірка й робочий цикл у `docs/jobs/build.md`, тут лише таблиці цієї частини моду. Кожен рядок: що потрібно → єдине місце в ядрі → чого не робити поруч із ним. Шапка названого файлу каже, як воно працює.

## Мова й тексти

| Що потрібно | Єдине місце | Не роби |
|---|---|---|
| Будь-який текст для гравця | `Lang.T` / `F` / `K`, україномовний ключ; англійська в `assets/lang` | голий рядок на екрані |
| Текст у полі чи списку (назва кнопки, професії, стан NPC) | `Lang.K("…")` там, де пишеться (інакше `l10n.js` його не бачить), `Lang.T` там, де показується. Те, що зберігається (ZDO, лог, пошук у тексті), лишається українським; стан NPC перекладає `NpcActor.StatusText` | писати в ZDO перекладене; `Title = "…"` без `Lang.K` |
| Текст у колі чи диску меню | `NpcMenu.Fit`: менший шрифт, тоді «…»; ширина підпису = відстань до сусідньої кнопки; шрифт для IMGUI: `BookArt.Words` (Alegreya) | фіксований розмір, що вилазить англійською; шрифт скіна гри |
| Скільки репліка на екрані | `RavenSpeech.Seconds(текст, Pace)`: одна функція для всіх (вид рядка: картка ворона, слова дару, сцена, людина, сюжетний ворон, балачка), над усіма `ReadScale`; час у секундах (налаштування, затримка гри) — `RavenSpeech.Hold` | своя формула часу показу |
| Хто говорить зараз | `Director`: кожен, хто хоче сказати сам, питає його | говорити повз нього |
| Складені фрази | `Patterns` і файли `*Patterns.cs`, `Composer` | фрази в коді логіки |
| Форми роду | `{m\|f}` розділяє літери, що різняться: `виріши{в\|ла}`; `Grammar` | `вирішив{\|ла}` |
| Голоси й мова | Мунінові суржик і русизми навмисні; Хугін дотепний і різкий (`docs/jobs/words-ravens.md`). Інтерфейс, люди й сюжет — чиста українська, без русизмів і кальок | «виправляти» Муніна; русизм чи калька в тексті інтерфейсу |

## Інтерфейс і налаштування

| Що потрібно | Єдине місце | Не роби |
|---|---|---|
| Книга воронів | `RavenBook*`; текст із підказкою золотий і з великої літери, без «?» | другий вид вікна |
| Скільки коштує сторінка книги | рядок `Book of ravens drawn` у лозі при закритті книги: кожна вкладка, побудова, розкладка, наступний кадр, що створилось при кліку (`BookArt.Late`). Форма чи картинка створюється раз і лежить у `BookArt`; дорога — здешев її там | готувати заздалегідь те, що можна зробити дешевим; своє кешування поза `BookArt` |
| Чи вміє гравець говорити з вороном | `RavenBook.Given`: у сюжетній збірці книгу дає хата Ейріка (дія `book`), без неї ворон лише сидить; клавіші, коло, голод (`Satiety.Draining`), смерть, прохання питають лише її. Хто мав ворона до сюжету, отримує книгу одразу. Без книги Провідник приносить лише теми `Bookless` (люди, `NoBook`); ворон від Гальдора без книги: тема `NoBook` одразу, а пролог скорочує свої паузи (умова `book`, розвилки `ownraven any, !book`) | свій замок у підсистемі |
| Клавіші | Свої клавіші моду: `RavenKeys`. Лише слухають, у гри й інших модів нічого не забирають. Стан кнопок гри (стрибок, присід) читай напряму через `ZInput` | перехоплювати клавішу |
| Коло дарів і наказів | `RavenRadial`, `OrdersMenu` | своє меню |
| Налаштування | ~35 головних у меню, решта в `tuning.cfg`. Баланс сервера іде через `ServerConfig` | новий рядок у меню без потреби |
| Ключі `Config.Bind` | без `= \n \t \ " ' [ ]`: один поганий ключ вбиває весь мод | |
| Консоль | `raven` у `Commands`, англійські слова; лише адмін, крім `raven book` | |
