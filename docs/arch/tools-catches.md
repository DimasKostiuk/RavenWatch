# Де що ловиться: яку помилку що тримає

Довідка до `docs/arch/tools.md`. Не читай цілим: шукай свою помилку (слово, назву кліпу, тег `[miss]`). Перед новим правилом перевірки чи новим уроком знайди тут, чи цю помилку вже щось ловить.

Кожен рядок із помилки, яка вже була. Новий урок іде якнайвище: ядро → `clipcheck` → VERDICT → документ (`docs/ANIMATION.md`). Аніматор тіла тут — `BodyAnimator` (BodyClips.cs).
