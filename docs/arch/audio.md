# Звук: хто за що відповідає

Розділ карти `docs/ARCHITECTURE.md`: правила й «Перед словом «готово»» там, збірка й робочий цикл у `docs/jobs/build.md`, тут лише таблиці цієї частини моду. Кожен рядок: що потрібно → єдине місце в ядрі → чого не робити поруч із ним. Шапка названого файлу каже, як воно працює.

## Звук

| Що потрібно | Єдине місце | Не роби |
|---|---|---|
| Будь-яка музика | `Audio.Music` / `MusicOff`: шари гра < бій < сцена, у кожного власник; поки хтось тримає, `MusicMan` нічого не вибирає (рейд, локація, плавання, ранок), тиша справжня. Треки свої й гри грають однаково. Чужий `all` не забирає музику в твоєї сцени. Перевірка `one-music` | `MusicMan.TriggerMusic`: його перебивають, а `""` глушить фонову музику надовго |
| Разовий звук зі сцени, кліпу, згасання, парних дарів, вітру крил, звук навпаки (`SoundBack`) | `Audio.Sound` / `Audio.PlayClip`, назви з `AudioBank` (`assets/story/sounds`): гучність, дальність, тон, 2D, слідування, зупинка. Звук гри зберігає все, що зробив би його ZSFX (варіанти, згасання, затримка, панорама, реверберація за відстанню), крім ліміту на кількість. Сухий через групу GUI; `wet` — через групу світу, поки світ не приглушений; `World` (дари) — завжди через неї. Файл, що ще читається, звук чекає (`SoundLate`). Звуки дарів через `RavenFx` лишаються там навмисно (користувач 2026-11-09) | свій `AudioSource` (перевірка `audio-source`); `Instantiate` ZSFX, коли важлива гучність: він переписує її щокадру, а два однакові за 0,2 с гра може відкинути |
| Довгий фон під сценою | `Audio.Bed`: без місця або з місцем (`SoundAsk` (Audio.cs) не `Flat`, `bed x hall 3 range 30`), тон і гучність можна міняти на ходу | свій цикл |
| Решта світу тихше | `Audio.Mix`: `world` (`SfxVol`, значення гравця повертається), `ambient` (вітер, море, фон), `music`, `voice`; кілька власників — діє найтихіший | писати в мікшер напряму |
| Заглушити звук гри за назвою | `Audio.Mute` (`sfx_footstep*`): новий не почнеться, цикл іде на нулі й повертається | патч на `ZSFX` |
| Звідки чути | `Audio.Ear`: очі гравця (як у грі) або камера сцени | рухати `AudioListener` |
| Звільнити все | `Audio.End(власник, с, обірвано)`: один виклик; сцена робить це в `StoryAudio.SceneEnd` | прибирати звук частинами |
| Слова сцени | `music`, `bed`, `mix`, `mute`, `unmute`, `ear`, `sound`: `StoryAudio` (шапка) | |
| Що зараз звучить | `raven audio`, кожна зміна в лозі з префіксом `Audio:` | |
| Додати чи налаштувати звук | вкладка «Звуки» (`SoundPanel`, `raven sounds`): звуки гри, файли й каталог в одному списку; клік по назві — слухати через ядро зі своїми гучністю, тоном, дальністю, 2D, `wet`, на відстані, і «Зберегти» рядком у `assets/story/sounds` (`AudioBank.Save`, лише на машині автора). Файл: покласти в цю теку й «Оновити список». Пульт: фон, `mute`, `ear`, голос воронів. `tools/game_sounds.txt` пише сама гра, `storycheck` звіряє з ним назви | правити каталог без прослуховування; копії звуків у `config` |
