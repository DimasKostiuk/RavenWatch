# RavenWatch — для авторів моделей

Це особлива збірка RavenWatch для тих, хто робить моделі для мода: шапки й речі для воронів, жердини, столи, предмети. Майстерня в ній відкривається клавішею, а готові моделі одним кліком пакуються в архів. Для гри на сервері вона не годиться.

## Встановлення (раз)
1. У r2modman створи **новий профіль** (наприклад, «RavenWatch моделі») і постав у нього **BepInExPack Valheim**.
2. r2modman → **Settings → Import local mod** → вибери цей zip-архів → Import.
3. Запусти гру через r2modman (Start modded), створи або відкрий **свій світ** (одиночна гра). Тестові інструменти працюють лише там, де ти господар світу.

При вході у світ у кутку з'явиться підказка. Якщо в персонажа нема воронів, у сумці будуть **Хугін і Мунін**: правий клік — і ворон сідає на плече.

## Клавіші
- **F7** — тестове вікно; вкладка **«Майстерня»**.
- **F8** — мишка вікну або грі (щоб покрутити камеру чи походити).

## Як зробити модель
1. Ліворуч — деталі з гри: пошук, клік — додати. Праворуч — деталі моделі: місце, поворот, розмір, колір.
   - **Ефекти** (вогник, іскри, дим, світло): у деталі, що має свій ефект (свічка, вогнище…), — кнопка **«Живий ефект: є/нема»**. Або вкладка каталогу **«Ефекти»**: лише ефект, без самої деталі, ставиш куди хочеш (на сцені його видно по блакитній кульці); **«Відтінок»** фарбує його в свій колір.
2. Знизу дай **назву** й коротке **«Що це»**.
3. **«Для мода»** — для чого модель:
   - **Річ для ворона** → «Куди»: **Спина / Шия / Лапи / Шапка**. Ворон на картинці; точка 0 — його кістка (спина, основа шиї, ліва лапа чи голова). Права лапа — дзеркально, сама. Для шиї: галочка «Рухається з шиєю» (зніми для кулона на грудях).
   - **Жердина** — потрібне «+ Місце ворона» (куди сяде).
   - **Стіл ворона** — станція, на якій майструють речі для воронів.
   - **Предмет** — новий предмет (стос, вага, де майструвати, ціна) або новий вигляд Каменя долі.
4. **«Зберегти»**.

## Як підігнати річ чи шапку на вороні
Книга воронів (**G → Ворони → книга**) → вкладка **«Вбрання»**. Речі з Майстерні з'являються там, щойно їх збережено. Клік — надіти; праворуч — панель **«ПІДГОНКА»** (крок, зсуви в сантиметрах, повороти, розмір, окремо для Хугіна чи Муніна). Під картинкою — ракурси, зум, **Стоп** (ворон сидить рівно), **Стоїть / Сидить / Летить**. Сіло добре — **«Готово»**.

## Коли модель готова
1. У Майстерні відкрий модель → **«☐ Готово для мода»** → стане **«✓ Готово для мода (твоє ім'я, дата)»**. Готові моделі в списку позначені ✓.
2. Коли готових кілька — **«Запакувати готове»**. На **робочому столі** з'явиться `RavenWatch-моделі-<ім'я>-<дата>.zip` (з моделями, посадками з книги і списком).
3. Надішли цей архів автору мода (Telegram).

## Правила, щоб модель потрапила в мод
- **Лише деталі з гри** (фільтр «Гра» в каталозі). Деталі з інших модів і файли з «Ассетів» у мод не підуть — при пакуванні буде попередження, а в архіві — «список.txt» з ними.
- **Назви — свої, не повторюй чужих** (моделей у моді вже чимало).
- Річ для ворона роби на **найбільшому** вороні (як на картинці): менші носять її пропорційно меншою.
- Не роби дуже важких моделей: сотні деталей на одній речі гальмуватимуть у грі.

Файли моделей лежать у `BepInEx/config/RavenWatch/models` (текстові, їх можна відкрити й подивитися).
